# Original Manifold Golf prototype

`Manifold_Golf-20260804T015706Z-1-001.zip` is the untouched archive Brenden supplied on 2026-08-03. It contains ten Python/Pygame/PyOpenGL experiments written in May 2025:

- the flat UV-space putter and metric-vector view;
- seam-safe live trails;
- the first 3-D torus viewer and optimized display-list renderer;
- ball, hole, lighting, and camera experiments;
- Gaussian normal-displacement hills with tuned deflection/braking; and
- the final height-colored torus variation.

The browser exhibit is a clean TypeScript/Canvas port informed by this lineage. Do not rewrite this archive in place; preserve it as the historical source and make later work in the website implementation.
